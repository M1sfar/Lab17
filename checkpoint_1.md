## 1. Реестр расхождений и инфраструктурных несоответствий

В ходе первичного экспресс-анализа пакета поставки (`release_packet.json`) и технической спецификации учебного сервиса заявок (`service_spec.md`) были выявлены следующие расхождения между проектными требованиями и фактическим состоянием сборки:

| Идентификатор | Компонент / Требование | Описание обнаруженного расхождения | Критичность |
| :--- | :--- | :--- | :--- |
| **ERR-01** | Документация (Руководство) | В пакете поставляется руководство оператора устаревшей версии `1.4.2`. В нем полностью отсутствуют инструкции для новой функции `category_required` и параметры `idempotency_key`. | **Критическая** |
| **ERR-02** | Тест T04 (`R_RESTORE`) | Инфраструктурный сбой автоматического теста восстановления данных из бэкапа. Статус: `blocked`. Причина: `restore-target-unavailable`. | **Блокирующая** |
| **ERR-03** | Тест T05 (`R_PERFORMANCE`) | Полное отсутствие результатов прогона нагрузочного тестирования. Статус: `not_run`, доказательство (`evidence`): `null`. Перцентиль скорости ответа не подтвержден. | **Критическая** |
| **ERR-04** | Конфигурация среды | Несоответствие версий окружения. В спецификации заявлена поддержка Python 3.11/3.12 и PostgreSQL 15/16. Фактическая валидация параметров среды сборки в пакете не зафиксирована. | **Средняя** |

## 2. Паспорт выпуска (Черновой вариант / Сведения о релизе)

* **Идентификатор релиза:** `1.5.0-rc1`
* **Контекст анализа:** Учебный кейс `DOC-17` (Маркеры: `DEMO-COMMIT`, `synthetic-log`). Фиктивные адреса внешних журналов и реальные Git-хеши отсутствуют по условиям учебной задачи.
* **Целевая среда развертывания:** Linux x64, Python 3.11/3.12, PostgreSQL 15/16. Минимальный объем свободного дискового пространства — 2048 МиБ.
* **Схема данных:** Переход со схемы `S1` на новую расширенную схему `S2` (включает миграцию данных `M015`).
* **Параметры конфигурации пакета:** `APP_PORT: 8081`, `DB_HOST: "lab-db-01"`, `DB_NAME: "service_lab"`, `ATTACHMENTS_DIR: "operator_guide"`.
* **Статус проверки бэкапа (`last_restore_test`):** Данные отсутствуют. Заполнение пробела вымышленными датами и успешными результатами запрещено регламентом аудита.

## 3. Параметрическая матрица трассировки требований

Карточка покрытия архитектурных и функциональных требований спецификации результатами автоматизированных тестов из пакета поставки:

* **`R_CREATE` (Создание заявок операторами):**
  * *Тест:* `T01`
  * *Статус:* `passed`
  * *Доказательство:* `synthetic-log-001`
  * *Вывод:* Требование формально выполнено ПО, но заблокировано со стороны документации (нет описания полей).

* **`R_ACCESS` (Разграничение прав ролей):**
  * *Тест:* `T02`
  * *Статус:* `passed`
  * *Доказательство:* `synthetic-log-002`
  * *Вывод:* Матрица прав доступа (`operator_a`, `operator_b`, `technician`, `manager`) соответствует коду.

* **`R_IDEMPOTENCY` (Защита от дублирования запросов):**
  * *Тест:* `T03`
  * *Статус:* `passed`
  * *Доказательство:* `synthetic-log-003`
  * *Вывод:* Механизм фильтрации повторных транзакций по `idempotency_key` успешно прошел автоматическую проверку.

* **`R_RESTORE` (Резервное копирование и восстановление):**
  * *Тест:* `T04`
  * *Статус:* **`blocked`**
  * *Доказательство:* `restore-target-unavailable`
  * *Вывод:* **Блокирующий дефект.** Целевая платформа восстановления недоступна. Откат системы в случае аварии не гарантирован.

* **`R_PERFORMANCE` (Нефункциональные требования к скорости работы):**
  * *Тест:* `T05`
  * *Статус:* **`not_run`**
  * *Доказательство:* `null`
  * *Вывод:* **Критический дефект.** Проверка удержания перцентиля скорости ответа p95 на уровне $\le 800$ мс при нагрузке в 1000 одновременных заявок не проводилась.

## 4. Список неразрешенных вопросов и ограничений первой пары
1. Полное отсутствие инфраструктурного доступа к среде развертывания тестов производительности (`T05`).
2. Необходимость ручной переработки и актуализации текста Руководства оператора из-за поставки устаревшего файла версии 1.4.2.
3. Ограничение взаимной проверки: аудит пакета на данном этапе выполняется аналитическим методом индивидуально, верификация со стороны внешнего партнера (peer review) отсутствует.
